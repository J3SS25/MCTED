# Reporting Security Issues

We take security vulnerabilities seriously. If you discover a vulnerability in MCTEB, please **do not** open a public GitHub issue.

Instead, please report it privately by emailing the project maintainer or the Municipality of Basco IT office. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof-of-concept code (redact any personal data)

We aim to acknowledge reports within 72 hours and to provide a resolution timeline within 7 days.

Thank you for helping keep this municipal service secure.
