# MCTEB Audit Records

This directory contains audit reports and review prompts for the MCTEB system.

## Contents

| File                | Description                                                               |
| ------------------- | ------------------------------------------------------------------------- |
| `Report.md`         | Development audit — architecture, code quality, and implementation review |
| `Security_Audit.md` | Security audit — authentication, authorization, input validation          |
| `UI_UX_Audit.md`    | UI/UX audit — accessibility, usability, design consistency                |
| `Prompts/`          | Audit prompt templates used to generate or regenerate audit reports       |

## Running a New Audit

Use the prompt templates in `Prompts/` as inputs to an AI-assisted review session, then save the resulting report here with the date in the filename (e.g., `Report_2026-11.md`).
